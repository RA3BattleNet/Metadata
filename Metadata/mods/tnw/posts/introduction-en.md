# Red Alert 3: The New World
## A Large-Scale Mod That Rewrites the Battlefield

*The New World* is a large-scale *Red Alert 3* mod by KiritsuguQi. While keeping the three original factions, it rebuilds power, economy, unit stats and combat mechanics for a faster pace, giving both PVP matches and PVE scenarios a completely new set of options.

---

## Gameplay Features

* **Power Plant Upgrades**: A power plant's special ability upgrades the power plant itself, so energy management is no longer just about stacking more structures.
* **Epic Units**: Epic units can be produced straight from the Construction Yard, giving the late game a decisive heavyweight anchor.
* **Water Construction**: Every structure can be placed on water, erasing the boundary between naval maps and land bases.
* **Interactive Map Objects**: Many neutral, interactive objects are placed across the maps, adding extra variables to tactical choices.
* **Teammate Synergy**: You can receive upgrades from teammates or use their structures as construction prerequisites, greatly increasing the payoff of team play.
* **Wonder System**: A Wonder can be built in a defense slot; once completed a countdown starts, and when it finishes you win the game outright.
* **Red Alert**: When the threat indicator in the lower left corner turns red, any structure with production capability can enable the Red Alert button, doubling production speed and granting funds.
* **Unique Opening Introduction**: A dedicated opening presentation is prepared for players.

---

## Multiplayer Note

The mod changes a large number of unit stats and combat mechanics, and the pace is faster than vanilla. When playing online, make sure everyone is on the same version to avoid desyncs.
