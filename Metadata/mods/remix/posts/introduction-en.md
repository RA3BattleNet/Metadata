# REMIX

REMIX is a Red Alert 3 mod by KnightVVV, in development since 2018 and still being updated.

## Features

- **Reworked Top Secret Protocols**: all 45 protocols have been remade.
- **New units**: all three factions gain new units, including more powerful tier-4 units.
- **New maps**: a large number of new maps, some of which come with their own special mechanics.
- **Fixes and polish**: a long list of original game bugs fixed, and the details of existing units reworked.

## Requirements

Red Alert 3 only. Uprising is not supported.
