使用说明与预览边界

三步走

  1. 导入：选择 mods/<id>/<id>.xml，或直接选整个 Mod 文件夹。文件夹会同时绑定 images/ 与 posts/ 下的图片和 Markdown。
  2. 编辑：控件、背景、Logo、介绍、友情链接。Logo、背景和链接图标都可以在对应位置直接点「导入图片」，不需要先建 ID；程序按固定规则生成 <mod>-logo、<mod>-bg-N、<mod>-link-N，Source 写到 images/。
  3. 导出：可以只导出 XML，也可以在「导出」里下载 ZIP。ZIP 结构为 mods/<id>/<id>.xml + images/ + posts/ + manifests/，只打包本地已有文件。

预览边界

  • 预览只实现客户端已有的字段映射：ARGB / CSS 颜色、按钮三态、九宫格 Logo、背景图与底色、Markdown 正文、链接栏。
  • 主题字体、按钮间距、卡片圆角、磨砂强度属于客户端主题，不是 XML 字段，预览用的是工具自己的近似主题。
  • Include 会在你导入整个 Mod 文件夹时用来查找图片和 Markdown，但不会合并或导出到主文件；InheritFrom（Base）仍不解析。
  • 正文里的相对图片路径在预览时会按 Markdown 所在目录解析；客户端以实际发布地址为准，正式数据建议用完整 URL。
  • 友情链接的 Languages 会写进 XML；当前客户端展示全部链接，预览按当前语言取显示名，不隐藏其他链接。

导出与校验

导出只改 Style、Posts、Links 与资源登记，其它节点、注释和属性原样保留。校验覆盖 XSD 里的颜色格式、数值范围、Logo 锚点、URL、语言标签、ID 唯一性与引用完整性；最终仍以仓库构建为准。

ZIP 始终导出完整文件，不受「仅 Style」范围影响。远程图片、没有本地文件的资源不会被打包，导出提示会列出缺少数量。

数据安全

所有解析、预览和导出都在本机浏览器里完成，不上传任何 XML、图片或 Markdown。关闭页面后未导出的改动会丢失。
